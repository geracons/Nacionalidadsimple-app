# APK de prueba — Nacionalidad Simple

Versión 1.0.0 para Android (arm64, móviles de 2017 en adelante).

**Instalar:** abre `NacionalidadSimple.apk` en el móvil → «Ver sin formato / Download» → abre el archivo
descargado y permite «instalar apps de origen desconocido» cuando Android lo pida.

Es una compilación de prueba firmada con un certificado de desarrollo (no apta para Google Play).
